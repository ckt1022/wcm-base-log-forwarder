# Clean Files Skill

根據使用者提供的參數，清除指定資料夾下的特定名稱檔案。

## 使用方式

`/clean-files` 後面接參數：`<資料夾路徑> <檔案名稱或模式>`

例如：
- `/clean-files ./dist *.log`
- `/clean-files ./src .DS_Store`
- `/clean-files ./build __pycache__`

## 執行步驟

1. 解析 $ARGUMENTS，取得目標資料夾路徑和檔案名稱/模式
2. 先列出符合條件的檔案，讓使用者確認（避免誤刪）
3. 確認後，執行刪除指令
4. 回報已刪除的檔案清單和數量

## 注意事項

- 刪除前必須先列出預計刪除的檔案讓使用者確認
- 若資料夾不存在，提示錯誤
- 支援遞迴搜尋子資料夾（使用 `find` 指令）
- 操作完成後顯示摘要
